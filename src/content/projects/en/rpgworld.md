## The problem

A learning project for object-oriented programming in Java: model a role-playing world with its entities and rules.

## What I built

A small role-playing game in Java, built as a pair with Valentin Martins. The repository holds the source code, a Maven build and a JSON save file.

## Technical choices

Java and Maven for the framework, and a save serialized as JSON to keep the state of a game.

## What I take from it

A learning project done as a pair, which had me model a game state to save and reload. The repository is not documented in detail.
