## The problem

An eco-design project: build a useful application using as few resources as possible.

## What I built

A personality quiz app that tells the user which character matches them, with several quiz universes (athlete, YouTuber, singer, manga, movies, football).

## Technical choices

A static front end in HTML, CSS and JavaScript, no framework, and a small Node.js server: few dependencies, hence little weight to transfer.

## What I take from it

Page weight as a design criterion: no framework, few dependencies. It is a small project, left as it is.
